# WebAssembly

`make wasm` links the portable serializer core into a module that browsers,
workers and Node.js can instantiate. `make portable` also checks cross-compilation,
but its `.o` files are relocatable objects rather than the supported browser artifact.

## Build and run

Install Clang with its WebAssembly backend, LLD, make and Node.js 18.13 or newer:

```sh
make wasm test-wasm
```

The result is `build/wasm/melodica.wasm` and `build/wasm/melodica.mjs`. No SDK,
package manager or JavaScript dependencies are needed to build the binding.
`NODE`, `WASM_CC`, `WASM_TARGET` and `BUILD` can be overridden. For example:

```sh
make wasm test-wasm WASM_CC=clang-18
make wasm test-wasm WASM_CC='zig cc' WASM_TARGET=wasm32-freestanding BUILD=build-zig
```

Build and serve the browser example:

```sh
make wasm-example
python3 -m http.server --bind 127.0.0.1 --directory build/wasm 8080
```

Open `http://localhost:8080/` in Firefox or Chromium. The page loads the module,
checks ABI version 1 and displays a station-list request generated by WASM.
It uses sample data and sends no service requests.

## JavaScript

Deploy both build files in the same directory, then import the binding:

```js
import { loadMelodica } from './melodica.mjs';

const melodica = await loadMelodica();
const bytes = melodica.stationListRequest('example-token', 12345);
console.log(new TextDecoder().decode(bytes));
// {"returnAllStations":true,"userAuthToken":"example-token","syncTime":12345}
```

The default module URL is resolved relative to `melodica.mjs`, including when the
page is served from a nested path. To choose another location, pass a URL or URL
string. You can also pass a `Response`, `ArrayBuffer`, typed-array view or compiled
`WebAssembly.Module`. Node.js can load local bytes directly:

```js
import { readFile } from 'node:fs/promises';
import { loadMelodica } from './build/wasm/melodica.mjs';

const melodica = await loadMelodica(await readFile('./build/wasm/melodica.wasm'));
console.log(new TextDecoder().decode(melodica.urlEncode('A b/+~')));
// A%20b%2F%2B~
```

| Binding | Result |
| --- | --- |
| `abiVersion` | Numeric ABI version, currently `1` |
| `urlEncode(input)` | URL-encoded bytes |
| `jsonEscape(input)` | Escaped JSON string contents, without enclosing quotes |
| `stationListRequest(token, syncTime)` | Complete station-list JSON request bytes |

Inputs accept strings encoded as UTF-8 or `Uint8Array` values. Results are copied
`Uint8Array` values: embedded NUL and non-UTF-8 bytes are preserved, and later calls
cannot overwrite earlier results. Decode only when the input is known to be text.
`syncTime` must be an integer from `0` through `4294967295`; wasm32 uses a 32-bit
`uintptr_t`. Invalid values throw instead of silently wrapping.

Serve `.wasm` as `application/wasm` to enable streaming compilation and `.mjs` as
a JavaScript module. The loader falls back to buffered compilation when the WASM
MIME type is missing or incorrect. HTTP errors, malformed modules and ABI
mismatches are reported to the caller. A restrictive Content Security Policy
must permit WebAssembly compilation; see [MDN's loading documentation][loading].

## Raw ABI and memory

The module exports `memory`, `__heap_base` and all seven public `melodica_*`
functions from `include/melodica.h`. It has zero imports and no start function.
There is no WASI, Emscripten, malloc, networking, filesystem or background thread.
All pointers and lengths are unsigned 32-bit offsets into the exported memory.

Memory starts at 128 KiB and can grow up to 16 MiB. The binding reuses scratch
space starting at `__heap_base`, beyond the C stack and static data. Input and
output coexist in that space, so the maximum input size depends on the operation's
expansion. Capacity failures throw. Each call is synchronous; use a worker if
large payloads would interfere with rendering.

For direct ABI calls, reserve your own non-overlapping input/output buffers at or
above `__heap_base.value`. A source pointer of zero means NULL, including for an
empty input; use a nonzero pointer with length zero for an empty string. Output
sizes exclude any NUL terminator. A null output pointer queries size, and an
undersized output buffer receives no writes. After `memory.grow()`, obtain fresh
views from `memory.buffer`: [growth detaches old views][growth].

`make test-wasm` executes the linked artifact and binding. It checks their export
and import contract, byte results, no-write behavior, memory growth and loading
over HTTP. Compilation alone does not establish that a WASM build works.

## Browser audio and profiling

This target supplies the standalone serializer API. It does not export the full
historical `piano.h` API, decode tracks or drive audio. The Epimetheus web client
currently selects a Dart stub; adding these build files does not wire that client
to WASM. See [client coverage](client-coverage.md).

A Firefox stack ending in `audioipc2` → `mio::Poll::poll` → `syscall` is consistent
with the audio IPC thread waiting for events. Its percentage is the share of the
selected samples, not a CPU-utilization measurement. [Mozilla documents][sampling]
that Gecko samples idle threads too. Investigate the page's console, rejected
playback promises and active JavaScript/WASM thread before attributing an audio
problem to the serializer.
